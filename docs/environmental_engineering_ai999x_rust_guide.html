environmental-engineering: the Environmental Engineering program, user guide

environmental-engineering-ai999x 1.6.0, Rust build: command line, desktop app and browser. Creator / engineer: Ibnul Jaif Farabi · Company: AI999X · support@ai999x.com

Environmental Engineering covers Gaussian plume dispersion and plume rise, BOD and Streeter-Phelps oxygen sag, water and wastewater treatment design, activated sludge, disinfection CT, Henry's law and air stripping, noise and solid waste. This guide is about environmental-engineering, the model as a self-contained program for Windows and Linux: 132 capabilities in 14 topics, answered on your own computer with no network, no Python and nothing else to install. The same compiled model runs in the AI999X desktop app and in the browser on the model's page (https://www.ai999x.com/models/environmental-engineering-ai999x/); the Python package (pip install environmental-engineering-ai999x) has its own guide. 3. Writing inputs

Inputs are written name=value, one per argument; environmental-engineering info <capability> lists the names. Quote an argument that holds a space or brackets (bash, zsh and PowerShell all accept double quotes). The answer always states each input as it was read, converted to SI, so a misread unit is visible at once.

kindexamplehow it is read
a number with a unit"R=0.128 nm"any unit of the same kind; converted to SI
a number in SIR=1.28e-10no unit means the SI unit shown by info
a choicestructure=FCCone of the values info lists
a list or vector"v=[1, 2, 3]" or "v=1, 2, 3"brackets keep it a list
a matrix"A=[[1, 2], [3, 4]]"one list per row
true / falseinclusive=truefor yes/no options

An equation can be solved for any of its quantities: give the others and add --target <symbol>. Without --target, the program solves for the quantity the capability is named after.

4. Outcomes and exit codes

The program never guesses a number: when it cannot answer, it says why and exits with status 1, so a script can tell an answer from a refusal without reading the text.

outcomemeaningexit status
SOLVEDthe answer: every output with its unit, the method, the inputs in SI, the conditions assumed0
NEEDS_INPUTan input is missing; the message names it and shows a complete call1
INVALID_INPUTa value or unit of the wrong kind, an unknown input name, or a value outside the conditions1
AMBIGUOUSthe inputs allow two different answers; say which one is meant1
OUT_OF_SCOPEthe model has no capability for this, or the result would not be meaningful1
(usage)a command the program does not know: it prints its usage2

5. Scripts and agents: batch and JSON

environmental-engineering solve ... --json prints one answer as one line of JSON. environmental-engineering batch reads one request per line on standard input and writes one JSON answer per line, in order, starting the program once for any number of requests. A request is {"key": "<capability>", "inputs": {"name": "value", ...}, "target": null}. In PowerShell, pipe the file in: Get-Content cases.jsonl | environmental-engineering batch. environmental-engineering catalog prints every capability with its inputs as JSON, to build forms or tool definitions.

answer fieldmeaning
outcomeone of the outcomes above
messagewhy there is no answer (empty when SOLVED)
value, unitthe main result in SI units
valuesevery output: [symbol, value, unit] (procedures)
targetthe quantity solved for
sieach numeric input converted to SI: [symbol, value]
assumptionsthe conditions the answer relies on
name, equationthe capability and its equation or method
import json, subprocess

reqs = [{"key": "<capability>", "inputs": {"name": "value"}}]
out = subprocess.run(["environmental-engineering", "batch"], input="\n".join(map(json.dumps, reqs)),
                     capture_output=True, text=True, check=True).stdout
answers = [json.loads(line) for line in out.splitlines()]
